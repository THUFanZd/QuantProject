## 研究结论

- 最终 10 个入选因子均满足 `|AR| > 10%`、`|SR| > 2`，最大两两绝对相关系数为 `0.277369 < 0.3`。
- 组合因子采用仅使用历史可观测 IC 的滚动 `IC_IR` 定权，避免以未来收益确定过去权重。
- 在 `2018-01-17` 至 `2026-03-23` 的有效回测区间内，增强组合年化超额收益为 `1.05%`，超额 Sharpe 为 `3.457`，超额最大回撤为 `-0.35%`。
- 超额月度胜率为 `82.83%`（`82/99`）；风格中性化后最大相关绝对值约为 `6.70e-17`，行业暴露离散度由 `0.275629` 降至约 `0`。

## 运行说明

本提交文件夹位于原项目仓库内时，可在仓库根目录执行：

```bash
python final_submission/03_portfolio_backtest/backtest.py \
  --data-root "/path/to/stock1000/data" \
  --weight-method ic_ir
```

脚本需要仓库公共依赖 `group_work/factor_lib/`、`code/stock1800/feature.py`，以及运行时提供的课程原始数据目录。课程数据实际截至 `2026-03-23`；主报告默认交易成本参数为 `0`。
